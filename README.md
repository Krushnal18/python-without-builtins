## Topics Covered

The notebook includes the following Python programs:

1. **Binary Search**

   * Implements binary search without using built-in search methods.
   * Searches for an element in a sorted list.

2. **Merge Two Sorted Lists**

   * Merges two sorted lists into a single sorted list.
   * Uses a two-pointer approach.

3. **Matrix Multiplication**

   * Multiplies two matrices using nested loops.
   * Demonstrates basic matrix operations.

4. **GCD (Greatest Common Divisor)**

   * Finds the GCD of two numbers using the Euclidean algorithm.

5. **Power Calculation**

   * Calculates the power of a number using a loop.
   * Example: `2^5 = 32`.

6. **Decimal to Binary Conversion**

   * Converts a decimal number into its binary representation.
   * Implemented without using a built-in conversion function.

7. **Binary to Decimal Conversion**

   * Converts a binary string into its decimal value.

8. **Armstrong Number**

   * Checks whether a number is an Armstrong number.
   * Examples include `153` and `9474`.

9. **String Concatenation**

   * Combines two strings without directly using the `+` operator.

10. **Remove Duplicates from a List**

    * Removes duplicate elements while maintaining the original order.
